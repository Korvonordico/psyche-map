# Security policy

Psyche Map has no server of its own: your map is kept in local files on your computer.

## Reporting a problem

If you find a security problem (for example a way for someone else to read or change your map), please do not open a public issue.
Use **Report a vulnerability** in the Security tab of this repository instead: only I will see it.

I am a single person working on this in my free time, so I cannot promise a fixed response time, but I will read every report.

## Supported versions

Only the latest version on the `main` branch gets fixes.
